## Steps

### Step 1: Restore the intake policy to `scripts/README.md`

Add a short "Adding a script here" section stating: (a) one-off debug/capture
scripts are born in the session scratchpad or a PR branch, not committed to
master's `scripts/`; (b) a script belongs here only when something references
it (`package.json`, `.github/workflows/*`, `docs/**`, `tests/**`, or
`README.md`) **or** its trigger/purpose is stated in this README; (c) the
KEEP rule above wins over any other signal at triage time. Keep it under ~15
lines; match the file's existing tone.

**Verify**: section present; `npm run format:check -- scripts/README.md`
passes if prettier covers md (if the command errors on scope, skip — CI's
format step is the gate).

### Step 2: Make the sync script's manifest true — and own the triplet

In `scripts/sync-agent-rules.sh`:

1. Correct the header comment: keep the `CLAUDE.md` line; state that
   `GEMINI.md`/`.windsurfrules` are local-only (gitignored) and manually
   maintained; drop the `.aider.conf.yml` and `.cursor/rules/project.mdc`
   lines (don't exist).
2. Add the code-review-graph doc as a generated output: introduce a source
   block (heredoc in the script, or better: read from a new tracked source —
   reuse the CURRENT content of `.cursorrules` verbatim as that source) and
   `write_file` it to `CODEBUDDY.md`, `QODER.md`, and `.cursorrules`,
   following the script's existing `write_file` mechanism and header-comment
   style. The three outputs must remain byte-identical to today's content
   (this step adds a generator, not new guidance).

**Verify**: `bash -n scripts/sync-agent-rules.sh` → exit 0;
`bash scripts/sync-agent-rules.sh` → exit 0; `git diff --stat` afterward
shows either no change to the triplet (content preserved) or only the
generator's standard header addition — if the script's convention adds a
"generated" banner, the three files change identically;
`md5sum CODEBUDDY.md QODER.md .cursorrules` → still one hash.

### Step 3: Fix the `.gitignore` comment

Line `~104`: drop the `CHANGELOG.md` mention ("README.md stays public").
Line `~105`: scope the generation claim ("some are generated by
scripts/sync-agent-rules.sh; the rest are manually-maintained local
pointers — see that script's header").

**Verify**: `grep -n "CHANGELOG" .gitignore` → no match in the private block.
